# Portfolio — Zhengkun Lou

一个滚动驱动的叙事站点。滚动不翻页，滚动是时间轴。

## 核心机制

整站只有一个 WebGL 场景、一条从 0 到 1 的滚动进度。各章不是「切页面」，而是同一批物体被滚动推着改变状态。真正的规则是这一条：

> **滚轮在不同章节推动的东西不一样——有时候它推动时间，有时候它推动相机。**

- `rain` 章：滚动 = 刹车。停手，雨就继续下；一滚，时间就冻住。
- `orbit` 章：时间被永久锁死，滚动改为推着相机绕行，穿过悬停的雨幕看作品。
- `restart` 章：时间解冻，雨落地砸出涟漪，镜头拉远，场景收回终端。

这条故事线最后收敛成一个变量：

```ts
const lock = chapterProgress('rain') * (1 - chapterProgress('restart'));
story.timeScale = (1 - lock) * (1 - freeze);
```

雨丝的拖影长度正比于「速度 × 时间流速」，所以时间一停，运动模糊自己收回去，雨丝就变成了悬在空中的水珠——不是两套素材，是同一个公式的两端。地面涟漪挂在同一个时钟上，冻住时也会停在扩散到一半的位置。

右上角的 `TIME ×0.00 / FROZEN` 读数是故意留的：这条规则本来只能靠感觉，有了读数就能被看见。

## 章节

| 章         | 画面                                     | 滚轮驱动             |
| ---------- | ---------------------------------------- | -------------------- |
| 00 BOOT    | 终端逐字写出一首对应七章的诗             | 自动播放（滚动锁死） |
| 01 REWIND  | 诗句倒流，字符按打字顺序的倒序脱离屏幕   | 时间 → 滚动接管      |
| 02 DEVELOP | 飞散的粒子重新聚拢，显影成研究工作的画面 | 滚动 = 显影进度      |
| 03 ARRIVAL | 相机转身，地面出现，主界面浮出           | 滚动 = 相机          |
| 04 RAIN    | 下雨。一滚雨就停                         | 时间 ↔ 相机          |
| 05 ORBIT   | 绕着冻结的雨幕转，每次滑动停在下一项工作 | 一次手势 = 一张展板  |
| 06 RESTART | 时间重新流动，镜头拉远，落回可交互的终端 | 滚动 = 解冻 + 后退   |

开场终端里的文字和第 1 章的粒子采样的是**同一张 canvas**，所以文字是在原地碎掉的，不是换了个东西再碎。

## 图版

`lib/plates.ts` 在运行时生成三张 SVG「深度学习博物画」：裂缝扩展、注意力矩阵、残差流。版式照搬十九世纪科学图版——压边框、图版号、衬线斜体标题、脚注、纸面颗粒——只是标本换成了研究对象。

用运行时 data URI 而不是静态资源，绕开 SVG 打包管线的不确定性。线描图版在采样时**只取墨不取纸**（`inkMax`），否则第 2 章只会显影出一块发光的矩形；暗色主题下再把墨色按比例提亮，色相留住，图版上的橙色标注原样放行。

## 简历在哪

在第 6 章那个终端里。开场的终端写出这段旅程的诗，结尾的终端回答关于写它的人的问题：

```
whoami  research  work  skills  education  projects  contact  resume  clear
```

不打字也能读完：进场会自动跑一次 `whoami`，所有命令都做成了可点的按钮。提交命令后，输入立即显示，回复逐步输出；连续提交会先补全上一条，`clear` 会立即停下并清屏。内容在 `src/story/config.ts` 的 `RESUME` 里，终端命令在 `src/story/lib/commands.ts`。

## 主题

日间是暖米色配橙，夜间是近黑色配橙。默认跟随系统，右上角的 DAY / NIGHT 可切换，选择存在 localStorage。

配色只有一个出处：`src/story/theme.ts`。它同时供给两边—— `applyThemeVars` 把值铺成 CSS 变量给样式表，`palette()` 给 Canvas 里的 uniform 和混合模式。亮色下粒子和雨会从加性混合切回常规混合，否则在纸面上只会越加越白。

注意：主题不能走 React Context——R3F v8 的 reconciler 不透传 context， Canvas 里面拿不到。它挂在 `state.ts` 那个模块级订阅 store 上。

## 滚动吸附

其余章节保持连续滚动；停稳后若靠近章节边界，就吸附到边界。进入 `orbit` 后，滚轮的一次滑动或手指的一次划动只推进一张展板，触控板连续发出的事件会归为同一个手势。相机转到展板正面后停稳，反向划动则退回上一张。最后一张之后直接进入结尾终端。停靠点见 `src/story/lib/snap.ts`。

## 性能

- 不可见的东西不渲染：雨（2 万个加性四边形）、粒子（2.8 万个点）、地面、展板都在 `useFrame` 里按不透明度切 `visible`。
- 所有 DOM 覆盖层共用一条 rAF（`lib/useRaf.ts`），后台标签页直接跳过。
- 切走标签页时 R3F 的 `frameloop` 置为 `never`。
- 颜色只在主题变化时解析，不每帧 parse 十六进制。
- `lib/quality.ts` 按设备分档：手机上粒子 28000→12000、雨 20000→8000、 dpr 封到 1.5。是减密度，不是关效果。
